# Archived v1 notebooks

These notebooks belong to version 1 of the project, a descriptive analysis of five US tech stocks (AAPL, MSFT, GOOGL, AMZN, NVDA) against SPY from Aug 2021 to Aug 2026.

They import the v1 modules (`src/performance_analysis.py`, `src/risk_analysis.py`, ...), which were replaced by the Nifty 50 pipeline, so they are kept for reference with their saved outputs and are not re-runnable on the current code. To run them, check out commit `0183cb9`.
